Blender → Unreal Export Prep Tool

A Blender Python tool for preparing selected mesh assets before exporting them to Unreal Engine.

Features:
- Validate selected mesh objects
- Auto-fix SM_ naming
- Apply scale and rotation
- Set pivot to bottom center
- Export from world origin
- Configure export path and Unreal destination path
- Choose normal mode: Keep, Flat, Smooth, Weighted
- Export FBX
- Save validation report
- Save Unreal manifest
